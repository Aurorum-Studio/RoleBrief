What it proves

This is not a generic summarizer. It proves that the same project evidence should produce different outputs for different people.

Why Box

Box stores the trusted project memory: source snapshots, role briefs, evidence maps, role strategies, manifests, and judge-ready artifacts.

Why Apify

Apify can crawl external URLs, normalize web evidence, and feed the same role-brief pipeline for a stable, repeatable demo.

Why Gemini

Gemini upgrades the local structured draft into a more natural role-specific brief, built only from the collected evidence.

Evidence collection mode

Requires USE_REAL_APIFY=true or this checkbox, plus APIFY_API_TOKEN in .env. This crawls the external URLs and normalizes them into evidence for the role briefs.

Box source import mode

Requires USE_BOX_READ=true or this checkbox, plus BOX_DEVELOPER_TOKEN and BOX_SOURCE_FOLDER_ID. This imports small text-like Box files as input evidence before Gemini generates role briefs.

Box export mode

Requires USE_REAL_BOX=true or this checkbox, plus BOX_DEVELOPER_TOKEN in .env. The local Box-style mirror is always written first, then uploaded to real Box.

Gemini AI mode

Requires USE_REAL_LLM=true or this checkbox, plus GEMINI_API_KEY in .env. Gemini rewrites the deterministic draft using only the collected evidence.
