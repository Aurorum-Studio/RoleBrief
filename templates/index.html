What it proves

This is not a generic summarizer. It proves that the same project evidence should produce different outputs for different people.

Why Box

Box stores the trusted project memory: source snapshots, role briefs, evidence maps, role strategies, manifests, and judge-ready artifacts.

Why Apify

Apify can crawl external URLs, normalize web evidence, and feed the same role-brief pipeline. Mock fallback keeps the demo stable.

Why Gemini

Gemini upgrades the local structured draft into a more natural role-specific brief, while the deterministic engine remains as a safe fallback.

Evidence collection mode

Requires USE_REAL_APIFY=true or this checkbox, plus APIFY_API_TOKEN in .env. If the crawl fails, the app automatically falls back to mock evidence so the demo still works.

Box export mode

Requires USE_REAL_BOX=true or this checkbox, plus BOX_DEVELOPER_TOKEN in .env. The local Box-style mirror is always written first, so the demo still works if Box upload fails.

Gemini AI mode

Requires USE_REAL_LLM=true or this checkbox, plus GEMINI_API_KEY in .env. Gemini rewrites the deterministic draft using only the collected evidence. If it fails, the local fallback brief is kept.
