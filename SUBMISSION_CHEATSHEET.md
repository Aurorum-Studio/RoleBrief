# Submission Cheatsheet

## Project name

RoleBrief AI

## Tagline

One project. Many audiences.

## One-liner

RoleBrief AI turns external web evidence and internal project notes into role-specific reports, tasks, and submission materials stored as a Box project memory.

## Problem

Teams often store project knowledge in one shared folder, but different stakeholders need different versions of that knowledge. Engineers, PMs, executives, sales, legal, and judges do not read the same documents for the same reasons.

## Solution

RoleBrief AI collects external evidence with Apify, combines it with internal notes, writes everything into a Box-style project memory, and uses Gemini to enhance audience-specific briefs plus a hackathon submission package, backed by a deterministic local generator.

## Why Box

Box is the trusted memory layer. It stores raw source snapshots, generated role briefs, evidence maps, metadata, task inbox files, and submission artifacts.

## Why Apify

Apify is the web evidence layer. It can crawl external URLs, normalize web content, and feed current context into the project intelligence pipeline.

## Why AI

Gemini translates the same evidence into role-specific decisions, not one generic summary. The app records which roles were Gemini-enhanced.

## Key differentiator

The product is audience-aware. It does not ask “what does this document say?” It asks “what does each stakeholder need to decide from this project memory?”
